# Experimental Web A integration
Full upstream GPL client is pinned, not a REST clone. Build artifact only, no public login yet. Configure repository variables RISEGRAM_WEB_API_ID and RISEGRAM_WEB_API_HASH using the app credentials accepted by the RiseGram server. The patch validates the RSA fingerprint, pins DC2 and routes browser WSS to the existing bot/API Railway domain, preserving the media domain on port 2401. The opt-in binary relay is disabled by default. Before deploying it, verify the private hostname, configure MTProto TELESRV_WEBSOCKET_ALLOWED_ORIGINS to the exact Pages origin, validate reverse proxy with an authorized beta account, audit official Telegram redirects and external services, and verify native sync. Keep Web login private until then. No production service has been modified by this branch. Do not expose admin API or private credentials.
