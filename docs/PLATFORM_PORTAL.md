# RiseGram multi-platform release plan

The platform portal is static, independent of the production Railway backend. GitHub Pages is the proposed no-cost host. Enable Pages > Source > GitHub Actions and permit this branch if required. The catalog deliberately does not claim that unavailable binaries can be downloaded.

Web: use the complete GPL-licensed gramsrv-adapted Telegram Web A fork, https://github.com/iamxvbaba/gramsrv-telegram-tt at 003316a04a173983d1df8f0fb9d8113708a1c582, not the discontinued REST web client. The upstream build accepts TELESRV_WEB_DC_HOST, TELESRV_WEB_DC_PORT, BASE_URL, APP_NAME, APP_TITLE, TELEGRAM_API_ID, TELEGRAM_API_HASH. Fork it under the RiseGram owner. Before publishing, replace RSA keys in src/lib/gramjs/crypto/RSA.ts with the current Android-pinned public RSA key only (fingerprint 0x41684b3ac49ce891); enforce RiseGram-only routing and HTTPS/WSS, including cached sessions and CSP; remove official Telegram login/QR redirects and external fallback. Verify the pinned server's /apiws upgrade via a TLS endpoint on the existing MTProto listener; never expose the admin port. Reuse the existing auth/OTP bridge, accounts and native economy; do not create a second chat database. Check message synchronization, sessions, group/channel permissions, gift inventory and Stars/Gram balances on Android and Web. No web login should be publicly exposed until these checks pass.

Native: Android APK, Windows x64 ZIP/EXE, Linux x64 TAR.GZ, macOS DMG and iOS IPA (sideload with authorized signing credentials). Desktop and Apple port branches remain experimental. Add actual release asset URLs only after successful build and smoke tests. No paid hosting or signing has been purchased.
